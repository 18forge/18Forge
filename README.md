# 18Forge

Landing page, built with Next.js and deployed on Vercel.

## Develop

```bash
npm install
npm run dev   # http://localhost:3000
```

## Edit the copy

All page text is in `app/content.ts`. Styles are in `app/globals.css`
(colors are the variables at the top).

## Deploy

The repo is imported into the 18Forge Vercel account; every push to `main`
deploys automatically.
